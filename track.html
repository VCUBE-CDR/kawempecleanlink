What the statuses mean

StatusMeaning
ReceivedThe website has accepted the report.
Under ReviewAn administrator is checking the information.
ReferredThe concern has been passed to a relevant contact where possible.
ClosedThe report has been closed after an update or explanation.
How real reference tracking would work
  1. A resident submits the report form.
  2. The server saves the report in a database.
  3. The system generates a unique reference number.
  4. The resident enters that number on this page.
  5. The server finds the matching record and displays its latest status.
Prototype limitation

This page displays an example record only. It does not search a database or retrieve live submissions. A working search requires a server-side program and database; HTML and CSS alone cannot perform that task.
